# 日本株デイトレ候補ランキング（研究ベース試作版）

主要な日本株30銘柄を対象に、5分足から「上昇継続」と「下落後の反発」を別々に採点し、GitHub Pagesへ表示します。

公開ページ：<https://syamashi.github.io/daytrade-ranker-jp/>

## 点数の考え方

- **上昇継続点**：市場に対する相対強度、15分・1時間モメンタム、同時刻出来高比、高値圏維持、価格効率、方向反転率、VWAP、売買代金
- **反発点**：当日の下落、直近15分のプラス転換、安値からの回復、VWAPへの復帰、出来高、価格効率、売買代金
- **売買しやすさ**：売買代金、相対出来高、極端すぎない実現ボラティリティ、価格効率、低い往復頻度
- **総合点**：継続点と反発点の高い方に、売買しやすさとデータ信頼度を掛け合わせた参考値

値幅の絶対額は株価水準に依存するため使いません。高値−安値を前日終値で割った値幅率、レンジ内位置、実現ボラティリティで比較します。波の多さは、5分足の方向反転率と「純移動÷総移動」の価格効率で表します。

詳しい研究根拠と限界は [RESEARCH.md](RESEARCH.md) を参照してください。

## 仮想注文候補と通知

毎日17:00（日本時間）に過去60日の5分足を学習60%・検証20%・未使用テスト20%へ時系列分割し、焼きなましで評価ウェイトと採用閾値を再計算します。ライブ画面は合格したモデルだけを使います。

次の条件がすべて成立したときだけ、GitHub Issueへ「仮想注文候補」を投稿します。

- 学習・検証・未使用テストの3期間が、往復コスト10bp控除後に平均・累積・Sharpeすべてプラス
- 学習80取引以上、検証と未使用テストは各20取引以上、データ取得エラーなし
- 検証期間の1取引平均が +0.10%以上
- 現在のモデル評価値が採用閾値以上、直近データ30分以上、東証の連続取引時間内
- 100株の参考購入額が30万円以下（仮想元本100万円）

通知には銘柄、100株の参考金額、15分の確認時間、参考損切り、検証期間のコスト控除後平均を載せます。これは期待収益の保証ではなく、自動発注もしません。GitHubのリポジトリで **Watch → All Activity** を選ぶとIssue通知を受け取れます。

Yahoo Financeの非公式エンドポイントを使う研究・教育目的の試作品です。取引所公式データではなく、遅延・欠損・停止の可能性があります。点数は将来の利益や上昇確率ではなく、バックテスト済みの売買推奨でもありません。自動注文は実装していません。
